# 企业资料使用与知识加工特性规格 v0.5

日期：2026-10-01。状态：待评审、待实现。本文件补充 features.md v0.4，不替换其 F01～F22 与 AC01～AC44。技术方案见 knowledge-retrieval-plan.md。

## 1. 目标与边界

用户导入资料后，能够知道是否可检索、是否完成知识加工、被哪些任务使用；系统能定位长文中的相关段落，提供版本明确的引用，并在来源变化后维护派生知识。

首个验收闭环：上传一篇超过 6000 字符的业务手册，问题答案位于后半部分；任务定位该段落并生成带引用的回答；修改或撤回原文后，旧片段和依赖知识不能继续交付，新版本经审核和加工后恢复使用。

原文、派生知识、当前业务运行证据分层处理。文档说“计划发布”不能证明已经部署；跨页链接、共同来源、搜索相关度不能直接变成业务事实或因果关系。模型生成结果是候选，不自动成为权威知识。

首期继续使用 Python/FastAPI 和关系型数据库，不强制专用图数据库、向量数据库或模型训练。多格式解析、向量检索、真实连接器分阶段加入。当前 fixed demo 身份不满足多用户上线要求。

## 2. 当前基线与缺口

已实现：文本导入与版本管理、人工审核/撤回、文档级依赖、失效检索阻断、只读模型工具、执行记录和任务预算。新模型输出预算默认 4096 token，可配置。

缺口：模型自行决定是否检索；提示偏向支付样例；完整子串搜索无排序；只读文档开头；没有分块和知识加工；调用额度耗尽后没有专门收尾；页面不能清楚区分上传成功与知识可用。

## 3. 新增特性

| 编号 | 特性 | 用户可见行为 | 优先级 |
|---|---|---|---|
| F23 | 指定资料与自动取证 | 任务可选择资料；未选择时按问题自动检索；明确本次资料范围 | P0 |
| F24 | 分段读取与原文定位 | 按标题/段落拆分长文；命中段落可展开并跳回原文版本 | P0 |
| F25 | 中文相关度检索 | 多词召回、中文双字切分、短语/标题加权；按相关度排序 | P0 |
| F26 | 上下文与执行预算 | 对检索片段、历史、系统提示、输出分别控制预算；为最终提交预留额度 | P0 |
| F27 | 资料使用透明度 | 展示检索词、候选、读取片段、版本、排除原因、最终引用；区分读取与支持结论 | P0 |
| F28 | 两阶段知识加工 | 分析来源后生成摘要、FAQ、实体和关系候选；处理状态和失败可见 | P1 |
| F29 | 候选校验与发布 | 来源定位、范围、类型、冲突和版本校验；审核差异后才成为正式知识 | P1 |
| F30 | 增量与可恢复维护 | 指纹去重、来源变更触发局部重建、队列重试/取消；旧任务不覆盖新版本 | P1 |
| F31 | 多来源支持与冲突 | 按事实登记支持/反证/适用范围；撤回一源后重新判定剩余证据 | P1 |
| F32 | 检索与维护质量巡检 | 固定案例评测召回与引用，检查无源、失效、冲突和待审积压 | P1 |

F23：指定资料为默认严格范围，扩展到其他资料需用户启用；无匹配时说明缺口，不回退到种子资料冒充依据。选中资料超过预算时选择相关片段并提示未覆盖部分，不整篇无界发送。

F24：片段 ID 绑定不可变文档修订；存储标题路径、序号、字符起止和内容哈希。解析文件的页码在解析器能提供时保留，不伪造页码。提供分页/片段读取；不能以“已读取全文”描述截断响应。

F25：搜索查询不能要求全文包含一个连续长句。多词允许部分匹配，同时报告命中词；空白、停用词和弱匹配需要明确行为。可选语义检索失败时降级并注明模式。所有召回通道必须先按项目、权限、来源状态过滤，再排序。

F26：检索调用与回答提交分别计数；临近额度时仅允许收尾提交。剩余预算不足以执行一批工具时，不执行部分批次，可进入一次有界收尾；没有合法证据则返回不足说明，不绕过引用校验。输出截断不保存成成功答案；有限重试不能取消全局时间/成本限制。

F27：本次“搜索到”“装入上下文”“模型引用”分别展示；不能把未被引用的候选说成答案依据。日志记录结构和受控摘要，不记录密钥或模型内部思考；原文显示仍须鉴权。

F28～F31：原文批准和派生知识批准独立。来源更新沿证据依赖计算影响，不沿一般业务关联传播失效。更新冲突、审核并发、未来生效和撤回保护延续 F17～F22。模型置信度只作辅助，不取代权威来源与审核。

## 4. 业务验收补充

| 编号 | 场景 | 通过标准 | 特性 |
|---|---|---|---|
| AC45 | 选择一篇资料提问 | 仅在授权且有效的选定资料中取证；引用可定位 | F23 |
| AC46 | 未选资料且问题不属于支付场景 | 自动检索用户资料；不强制引用支付种子 | F23 |
| AC47 | 答案在长文后半部分 | 命中该片段并读到相邻必要上下文 | F24 |
| AC48 | 文档修订后打开旧引用 | 显示当时版本及当前风险，不跳成新版本 | F24 |
| AC49 | 中文多词分散在不同段落 | 可召回并按命中与相关度排序，非连续句匹配 | F25 |
| AC50 | 无匹配或向量服务故障 | 无匹配说明缺口；向量故障按关键词降级并标明 | F25 |
| AC51 | 工具预算将耗尽 | 有证据时有界收尾；无证据不编造；不超过总预算 | F26 |
| AC52 | 输出截断 | 不标记成功；提示预算与停止原因，保留证据 | F26 |
| AC53 | 搜索有十篇，实际只读两篇 | 页面清楚区分候选与已读，不把十篇全部当引用 | F27 |
| AC54 | 回答包含资料未支持的结论 | 能追踪引用片段；评测判为不支持，不凭引用存在通过 | F27 |
| AC55 | 新来源加工完成 | 生成来源摘要与有证据定位的候选；不直接发布关系 | F28 |
| AC56 | 加工模型超时/输出无效 | 明确失败可重试，原文仍保留；半成品不进入正式检索 | F28 |
| AC57 | 审批时来源或目标版本变更 | 拒绝旧批准，重算差异并重新审核 | F29 |
| AC58 | 加工内容含无出处关系 | 拒绝正式发布并说明缺失依据 | F29 |
| AC59 | 相同内容重复导入或任务中断 | 无重复生效知识；恢复不重放已成功发布步骤 | F30 |
| AC60 | 旧 Worker 晚完成、权限单独变化 | 旧结果不能覆盖新代数；权限变化不被正文去重忽略 | F30 |
| AC61 | 一条事实有两来源，撤回其中之一 | 逐条重新评估支持程度，不整页直接删除或盲目保留 | F31 |
| AC62 | 同范围反证与不同版本规则 | 同范围保留冲突；不同范围分别适用，不按时间盲选 | F31 |
| AC63 | 巡检发现断引用、失效、无人认领 | 生成有负责人和截止时间的维护待办 | F32 |
| AC64 | 固定历史案例升级后回归 | 产出召回、引用、拒答、耗时/成本对比，下降可见 | F32 |

全部新增项目前为设计目标。测试数量不等于 AC45～AC64 已通过。本补充新增 10 项特性和 20 个场景；与 v0.4 合计 32 项特性和 64 个业务验收场景。

## 5. 界面交付

资料页：原文状态、索引状态、加工状态独立显示；版本/段落浏览；加工错误和重试；派生候选及受影响内容。

任务页：选择资料与范围、已取证片段列表、引用定位、预算/降级/截断提示。一般资料问答与业务状态排查分开选择；业务状态排查仍要求真实连接器证据。

审核页：原文差异与知识差异、支持/反证来源、适用范围、版本冲突；批准/拒绝的理由及影响清单。

维护页：索引失败、加工失败、冲突、超期复核、负责人、评测趋势；维护视图与正常问答可用知识分离。
